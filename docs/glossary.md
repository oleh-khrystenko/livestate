# Терміни

| Термін | Значення |
|--------|----------|
| **livestate** | Назва проєкту. Цифрова система самоврядування |
| **Ядро CyanShip** | Готова основа, на якій будується livestate: вхід, профіль, ШІ, інтерфейс. Див. [architecture.md](architecture.md) |
| **Конституція** | Базовий документ, який люди пишуть разом. Розбита на статті |
| **Стаття** | Окрема частина Конституції. До неї пропонують зміни |
| **Пропозиція** | Запропонована зміна до статті. Стає частиною Конституції лише після голосування |
| **Автор пропозиції** | Людина, яка подала пропозицію. Отримує бали репутації, якщо пропозиція пройшла і спрацювала |
| **Обговорення** | Повідомлення людей під пропозицією |
| **Аналіз ШІ** | Перевірка пропозиції: суперечності, наслідки, схожі пропозиції, чіткість. З посиланнями на конкретні місця |
| **Аналіз наслідків** | Частина аналізу ШІ, яку людина бачить перед голосуванням |
| **Голосування** | Єдиний спосіб ухвалити рішення |
| **Безперервне голосування** | Голосування ніколи не припиняється. Голоси можуть перерозподілятися будь-коли |
| **Поріг** | Частка голосів, потрібна, щоб рішення пройшло. Визначається заповідями |
| **Заповіді** | Базові правила прийняття рішень. Див. [commandments.md](commandments.md) |
| **Важлива зміна** | Зміна, яка приймається 2/3 голосів. Що саме вважається важливим, не визначено |
| **Базові права** | Права, які не змінюються взагалі. Перелік не складено |
| **Тема** | Розділ, у межах якого діє делегування і рахується репутація |
| **Делегування** | Передача свого голосу з конкретної теми людині, якій довіряєш. Можна забрати будь-коли |
| **Делегат** | Людина, якій інші віддали голоси з теми. Те саме, що представник або лідер у темі |
| **Відкликання голосу** | Повернення делегованого голосу собі |
| **Репутація** | Бали в темі за реальний внесок: пропозицію, яка пройшла і спрацювала |
| **Спільнота** | Група людей у ієрархії |
| **Клітина** | Група з 10 людей |
| **Орган** | Група зі 100 людей |
| **Тіло** | Група з 1000 людей |
| **Учасник** | Людина, яка увійшла на сайт. Може пропонувати, голосувати, делегувати |
| **Гість** | Людина без входу. Може читати все |
| **Прозорість** | Голосування, рішення, фінанси і дії представників відкриті |
| **Відкритий код** | Код системи доступний усім для перевірки |
| **ШІ** | Штучний інтелект. Помічник, який аналізує, але не вирішує. Див. [ai.md](ai.md) |
