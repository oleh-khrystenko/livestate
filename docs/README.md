# LiveState

LiveState це цифрова система самоврядування. Влада належить людям. Механізми прозорі й працюють як програма, а не як обіцянка.

Перший продукт: сайт, де люди разом пишуть нову Конституцію. ШІ допомагає аналізувати й покращувати текст. Рішення ухвалюють люди голосуванням.

## Як читати ці документи

Автор пропонує концепцію. Він не вирішує за суспільство.

Усе, що тут написано, є стартовою пропозицією. Будь-яке положення можна винести на голосування і змінити. Невирішені питання вирішує суспільство, а не автор.

## Для кого

- **Для учасників.** Людей, які хочуть впливати на правила, за якими живуть. Включно з тими, кому складно зі смартфоном.
- **Для читачів.** Будь-хто може читати Конституцію, пропозиції й підсумки голосувань без входу.
- **Для розробників.** Тих, хто будуватиме систему. Код відкритий.
